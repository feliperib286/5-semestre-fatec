# Atividade 2 - Previsão do Tempo (Flutter)

Projeto desenvolvido para a disciplina de Programação para Dispositivos Móveis II (Fatec), com o objetivo de consultar e apresentar a previsão do tempo utilizando a API do CPTEC/INPE.

## 📱 Funcionalidades Implementadas
- **Pesquisa de Cidades:** Consulta de localidades no serviço do CPTEC/INPE através do nome da cidade.
- **Previsão de 4 dias:** Exibição da data, temperatura mínima e máxima, índice UV e data de atualização.
- **Tradução de Siglas:** Conversão das siglas do CPTEC (ex: 'ps') para descrições compreensíveis (ex: 'Predomínio de Sol').
- **Gráfico de Variação:** Visualização das temperaturas máximas e mínimas através de um gráfico de linhas.
- **Tratamento de Erros e UX:** Indicadores de carregamento, mensagens para pesquisas sem resultados, tratamento de falhas de rede e opção de puxar para atualizar (Pull-to-Refresh).
